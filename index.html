01 / SOBRE O PROJETO

Incluir é criar espaço para todos os jeitos de existir.

+feito para
acolher

O Acolhe TEA é uma proposta de ambiente digital pensado para apoiar a organização da rotina, a expressão das emoções e o bem-estar.

Não existe uma única forma de ser autista — e também não existe uma experiência ideal para todo mundo. Por isso, reunimos ferramentas opcionais e personalizáveis, para que cada pessoa encontre o que faz sentido para si.
